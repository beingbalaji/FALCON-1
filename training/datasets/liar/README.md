# LIAR dataset

The LIAR dataset is not redistributed in this repository. Download it from the
original source and place the three files here:

```
training/datasets/liar/train.tsv
training/datasets/liar/valid.tsv
training/datasets/liar/test.tsv
```

Source: https://www.cs.ucsb.edu/~william/data/liar_dataset.zip

Citation: William Yang Wang. "Liar, Liar Pants on Fire": A New Benchmark Dataset
for Fake News Detection. ACL 2017.
